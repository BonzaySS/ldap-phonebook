# Changelog

All notable changes to this project are documented here.
The format follows [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
versions follow [Semantic Versioning](https://semver.org/lang/ru/).

## [1.0.0] — 2026-10-27

Первая публичная версия.

### Добавлено

- `install.sh` — установка на чистый Debian/Ubuntu одной командой: OpenLDAP,
  каталог, правила доступа, веб-интерфейс, systemd-служба.
- `uninstall.sh` — удаление интерфейса; данные каталога удаляются только по
  явному флагу `--purge-ldap`.
- Веб-интерфейс телефонной книги: четыре поля (предприятие, должность, ФИО,
  телефоны), добавление, правка, удаление, поиск, импорт и экспорт CSV.
- Вход по учётным записям каталога: `admin` пишет, `book` только читает.
- Импорт CSV (`import_phonebook.py`): UTF-8 и cp1251, разделители `;` `,` таб,
  русские и английские заголовки, режим `--update`.
- Правила доступа: анонимный доступ к каталогу закрыт, телефоны ходят под
  отдельной учётной записью только для чтения.
- Документация: `docs/INSTALL.md`, `docs/PHONES.md` (настройка Yealink/Fanvil),
  дымовые тесты `tests/smoke.sh`.
- CI: проверка синтаксиса, shellcheck, установка на чистой Ubuntu и прогон
  тестов, публикация tarball в GitHub Releases по тегу `v*`.

### Известные ограничения

- Поддерживаются Debian, Ubuntu и производные (Raspbian). RHEL/Alma/Fedora —
  не поддерживаются.
- Веб-интерфейс работает по HTTP; пароли передаются в каталог открытым текстом.
  Внутри локальной сети это обычная практика, за её пределами нужен TLS-прокси.
- Поиск по имени с клавиатуры телефона требует русской раскладки в языке
  аппарата либо латинских имён в записях.
