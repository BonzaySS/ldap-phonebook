# Changelog

All notable changes to this project are documented here.
The format follows [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
versions follow [Semantic Versioning](https://semver.org/lang/ru/).

## [1.2.3] — 2026-10-27

### Изменено

- По умолчанию подпись для телефона собирается **в одну строку**:
  `Энерком · Инженер · Чирcкий С.` Перенос на две строки теперь нужно включать
  явно (`PB_DISPLAY_MULTILINE=true`) — не все прошивки его показывают.

## [1.2.2] — 2026-10-27

### Добавлено

- Длинная подпись для экрана телефона переносится на вторую строку по границе
  разделителя — в экран влезает около 35 символов, слова не режутся.
- Настройки подписи: `PB_DISPLAY_MAX` (ширина строки, по умолчанию 35),
  `PB_DISPLAY_MULTILINE` (выключить перенос) и `PB_DISPLAY_NL` (символ переноса:
  `\n`, `\r\n`, пробел или пусто — если телефон не понимает перевод строки).

## [1.2.1] — 2026-10-27

### Изменено

- Подпись для экрана телефона теперь в порядке «организация · должность · ФИО»:
  `Энерком · Инженер · Чирcкий С.`
- Порядок и разделитель настраиваются переменными `PB_DISPLAY_ORDER`
  (`o`, `t`, `n`, `c`) и `PB_DISPLAY_SEP` — без правки кода.

## [1.2.0] — 2026-10-27

### Добавлено

- **Дерево по организациям.** Контакты лежат в ветках
  `ou=<организация>,ou=people,<base>`: ветка создаётся сама при первом контакте,
  при смене организации запись переезжает в другую ветку, контакт без
  организации остаётся в `ou=people`. База поиска для телефонов не меняется.
- **Список группируется по организациям** — заголовки групп в таблице.
- **Организация и должность на экране телефона.** Атрибут `displayName`
  собирается как «ФИО — должность, организация»; у Fanvil достаточно поставить
  `Display name = displayName`, у Yealink — `%displayName`.
- `packaging/migrate_tree.py` — переносит существующие записи в ветки и
  обновляет подпись.

### Изменено

- Рамка таблицы в веб-интерфейсе стала заметной, ячейки — компактнее.

## [1.1.0] — 2026-10-27

### Исправлено

- **Несколько номеров в одном поле.** Телефоны Fanvil (и Yealink) показывают
  только одно значение атрибута `telephoneNumber` и не умеют выводить несколько
  номеров из одного поля. Теперь номеров ровно три отдельных поля — рабочий
  (`telephoneNumber`), мобильный (`mobile`) и другой (`homePhone`), по одному
  значению в каждом. Старые записи с несколькими `telephoneNumber`
  раскладываются по свободным полям при чтении и при сохранении.

### Изменено

- Форма: вместо одного поля «Телефоны» три поля — «Рабочий», «Мобильный»,
  «Другой». Подписи совпадают с полями телефона (Telephone / Mobile / Other).
- CSV: экспорт пишет колонки `Телефон;Мобильный;Другой`; импорт понимает и их,
  и старую колонку `телефоны` со списком номеров (раскладывается по порядку).
- Импортёр на сервере (`import_phonebook.py`) тоже пишет по одному номеру
  в атрибут, лишние значения уходят в свободные поля.

## [1.0.0] — 2026-10-27

Первая публичная версия.

### Добавлено

- `install.sh` — установка на чистый Debian/Ubuntu одной командой: OpenLDAP,
  каталог, правила доступа, веб-интерфейс, systemd-служба.
- `uninstall.sh` — удаление интерфейса; данные каталога удаляются только по
  явному флагу `--purge-ldap`.
- Веб-интерфейс телефонной книги: четыре поля (предприятие, должность, ФИО,
  телефоны), добавление, правка, удаление, поиск, импорт и экспорт CSV.
- Вход по учётным записям каталога: `admin` пишет, `book` только читает.
- Импорт CSV (`import_phonebook.py`): UTF-8 и cp1251, разделители `;` `,` таб,
  русские и английские заголовки, режим `--update`.
- Правила доступа: анонимный доступ к каталогу закрыт, телефоны ходят под
  отдельной учётной записью только для чтения.
- Документация: `docs/INSTALL.md`, `docs/PHONES.md` (настройка Yealink/Fanvil),
  дымовые тесты `tests/smoke.sh`.
- CI: проверка синтаксиса, shellcheck, установка на чистой Ubuntu и прогон
  тестов, публикация tarball в GitHub Releases по тегу `v*`.

### Известные ограничения

- Поддерживаются Debian, Ubuntu и производные (Raspbian). RHEL/Alma/Fedora —
  не поддерживаются.
- Веб-интерфейс работает по HTTP; пароли передаются в каталог открытым текстом.
  Внутри локальной сети это обычная практика, за её пределами нужен TLS-прокси.
- Поиск по имени с клавиатуры телефона требует русской раскладки в языке
  аппарата либо латинских имён в записях.
